# 문서 찾아보기

과제: 컨테이너, k8s 인프라 구축 — MSA 애플리케이션 구축 운영 (11월 19일 ~ 25일)

보듬 동물병원 예약 시스템(AWS 3-Tier)을 서비스 3개로 나눠 컨테이너와 쿠버네티스에 올린다.
네 단계로 진행하고, 단계마다 그 런타임에서 테스트한 뒤 문서로 남긴다.

## 단계별 보고서

| 단계 | 무엇을 | 테스트 | 보고서 | 상태 |
|---|---|---|---|---|
| ① 앱 | 단일 WAS 를 서비스 3개로 나눔 | `msa\gradlew.bat build` (16개), `scripts\test-app.ps1` (28개) | [1-앱.md](1-앱.md) | 완료 |
| ② 컨테이너 이미지 | 이미지 6개, compose | `scripts\smoke.ps1` (54개, Apache 와 nginx) | [2-컨테이너.md](2-컨테이너.md) | 완료 |
| ③ 쿠버네티스 | 배포 파일(Kustomize), 로컬 클러스터 | `scripts\smoke.ps1 -Isolation k8s` (54개), `scripts\test-k8s-ops.ps1` (12개) | [3-쿠버네티스.md](3-쿠버네티스.md) | 완료 |
| ④ EKS | AWS 에 배포 | 같은 smoke 와 운영 동작 + EKS 에서만 볼 수 있는 것 10가지 | [4-EKS.md](4-EKS.md) | 틀만 있음. EKS 에서는 실행 전 |

보고서는 모두 같은 순서다: 무엇을 만들었나 → 어떻게 테스트했나 → 결과 → 발견한 문제와 조치 → 한계.

## 문제와 해결

작업하면서 부딪힌 문제 19개를 [문제와-해결.md](문제와-해결.md) 에 따로 모았다. 문제마다 증상(실제 출력) → 원인을 찾은 과정 → 원인 → 해결 → 확인 → 배운 점 순서다.

| 가장 볼 만한 것 | 내용 |
|---|---|
| 1, 2번 | 멈춘 서비스가 JSON 대신 500 HTML 을 돌려줌 → 로그로 원인을 찾고 Apache 의 한계를 `.asis` 로 넘음 |
| 3, 4번 | 초기 데이터가 전부 과거 → DB 가 뜰 때 그날 기준으로 만들어 뜨는 순서 문제까지 함께 풂 |
| 10번 | 서비스는 나눴는데 DB 경계가 없음 → 앱 코드를 고치지 않고 스키마·계정·뷰로 나눔 |
| 11번 | 강제 재생성이 실패 → 스키마를 가로지르는 외래 키가 원인. prod 에서 만나기 전에 시험으로 찾음 |

## 같은 기능을 층마다 다시 확인한다

로그인, 예약, 승인, 일정 조회라는 같은 기능을 런타임이 바뀔 때마다 다시 확인한다. 층이 하나 올라갈 때마다 그 층에서만 볼 수 있는 것을 더한다.

| 확인하는 것 | ① 앱 | ② Docker | ③ 쿠버네티스 | ④ EKS |
|---|---|---|---|---|
| 로그인 → 예약 → 승인 → 일정 | 통과 | 통과 | 통과 | – |
| 세 서비스가 같은 로그인 세션을 읽는다 | 통과 | 통과 | 통과 | – |
| 서비스는 자기 DB 스키마만 쓴다 | 통과 | 통과 | 통과 | – |
| 웹 서버가 경로를 서비스별로 나눈다 | 해당 없음 | 통과 | 통과 | – |
| 한 서비스가 멈춰도 나머지는 동작한다 | 해당 없음 | 통과 | 통과 | – |
| 버전 표시와 상태 쪽지 | 해당 없음 | 통과 | 통과 | – |
| 무중단 배포, 자동 복구 | 해당 없음 | 해당 없음 | 통과 | – |
| 자동 확장 | 해당 없음 | 해당 없음 | 설정만 확인 | – |
| 노드 장애, 가용 영역 분산, RDS | 해당 없음 | 해당 없음 | 해당 없음 | – |

"–" 는 아직 실행하지 않은 칸이다. ④ 열은 프로젝트 기간에 EKS 에서 실행하면서 채운다. 무엇을 어떤 명령으로 확인할지는 [4-EKS.md](4-EKS.md) 에 적어 두었다.

## 저장소 구성

| 폴더 | 내용 |
|---|---|
| `was/`, `cfn/`, `deploy/`, `loadtest/` | AWS 3-Tier 원본. 고치지 않는다 |
| `msa/` | 서비스 3개(Gradle 멀티 모듈), Dockerfile, 웹 서버 설정, DB 초기화 |
| `web/` | 소개 페이지와 예약 화면. 상태 쪽지와 버전 표시를 더했다 |
| `db/` | 스키마와 시드 생성기. 고치지 않고 이미지가 복사해 쓴다 |
| `scripts/` | `test-app.ps1`(①), `smoke.ps1`(②③④), `test-k8s-ops.ps1`(③④), `new-env.ps1`, `new-k8s-secrets.ps1` |
| `compose.yaml` | ② 의 실행 구성 |
| `gitops/apps/vet/` | ③④ 의 배포 파일 (Kustomize: base, components, overlays/dev·prod) |
