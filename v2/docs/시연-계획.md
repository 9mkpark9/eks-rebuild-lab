# 브라우저 시연 영상 계획 (마지막에 찍는다)

발표 15번 슬라이드의 시연(1분 30초)과, 시연이 안 될 때 틀 예비 영상을 겸한다. **실제 화면을 녹화한다.** 편집은 앞뒤 자르기만 한다.

## 찍기 전에

1. **접속 허용 주소를 지금 있는 곳의 IP 로 바꾼다.** ALB, NodePort, kubectl 은 설정한 IP 하나에만 열려 있다. 집이나 발표장에서는 IP 가 다르다.

   ```bash
   v2/infra/stacks.sh up network        # NodePort, kubectl (kubeadm)
   v2/infra/stacks.sh up eks            # EKS API
   KUBECONFIG=v2/_run/kubeconfig-eks v2/k8s/apply.sh eks          # ALB 의 허용 주소
   ```

2. 두 클러스터와 RDS 가 켜져 있는지 본다 (`v2/infra/stacks.sh status`, `kubectl get pods`).
3. 시험 계정: 보호자 `owner001`, 간호사 `admin1`, 원장 `vet1` (비밀번호 `test-only`, 로그인 화면에 공개된 시험용 값).
4. 녹화 도구: Windows 의 Xbox Game Bar(Win + Alt + R) 또는 OBS. 1920 × 1080, 브라우저 하나만.

## 순서 (약 1분 30초)

| 시간 | 화면 | 보여 줄 것 |
|---|---|---|
| 0:00 | 주소창의 ALB 주소 | EKS 의 ALB 로 들어온다 |
| 0:10 | 소개 페이지 → 로그인 | 보호자로 로그인 |
| 0:25 | 온라인 예약 | 반려동물, 진료 항목, 날짜, 시간 고르고 **신청 (등록)** |
| 0:45 | 내 예약 | 방금 만든 예약이 보인다 **(조회)**. 시간을 바꾼다 **(수정)** |
| 1:00 | 간호사로 다시 로그인 → 예약 현황 | 같은 예약이 보이고 승인한다 |
| 1:15 | 화면 아래쪽 | 응답한 web Pod 와 서비스 Pod 의 이름 (요청마다 바뀐다 = Pod 여러 개) |
| 1:25 | (선택) 터미널 `kubectl get pods` | Pod 2개씩, 노드 2a / 2c |

명세의 기능 기준(등록 · 조회 · 수정)과 "ALB 주소로 시연"을 한 번에 보인다.

## 예비

- 시연이 안 되면 이 영상을 튼다. 영상도 안 되면 앱 화면 캡처(`img/01 ~ 07`)를 넘긴다.
- 발표가 끝나면 자원을 지우고 남은 자원이 없음을 확인한다 (⑤ 7.4, 명세 ④ 비용과 정리).

## 녹화한 영상 (2026-11-25)

[video/시연-EKS.webm](video/시연-EKS.webm) — 1분 54초, 1600 × 900. EKS 필수 구성의 ALB 주소로 실제 앱을 조작하며 브라우저 화면을 그대로 녹화했다 (Playwright 의 화면 녹화). 앱의 응답과 데이터는 손대지 않았다. 화면 위의 자막과 빨간 점(마우스 위치), 빨간 테두리는 보는 사람을 위해 덧붙인 표시다.

| 시간 (약) | 장면 |
|---|---|
| 0:00 | 소개 페이지. 자막에 접속한 ALB 주소 |
| 0:10 | 보호자(`owner001`) 로그인 |
| 0:20 | **등록**: 콩이, 일반 진료, 11월 27일, 첫 빈 시간 → 신청 |
| 0:35 | **조회**: 내 예약에 방금 신청한 예약 (승인 대기) |
| 0:40 | **수정**: 시간 변경 → 오전 11:00 |
| 1:00 | 간호사(`admin1`) 로그인 → 11월 27일 → 승인. 상세의 "처리 WAS" 에 이 예약을 처리한 reservation Pod |
| 1:30 | 화면 맨 아래 줄 (응답한 web Pod · 서비스 Pod), "처리 WAS 분포" (reservation Pod 여럿) |
| 1:40 | 보호자로 다시 로그인 → 같은 예약이 「예약 확정」 |

**확인한 것.** 화면 아래 줄은 "마지막으로 응답한 Pod" 라서, 새로고침 한 번에 요청이 여러 개면 같은 이름이 보일 때가 있다. ALB 가 web Pod 둘에 실제로 나눠 보내는지는 `curl` 로 따로 쟀다: 10번 중 `web-…9xnjz` 5번, `web-…cr5lv` 5번 (캡처 없음). 그래서 영상의 자막은 "새로고침마다 바뀐다"가 아니라 화면에 보이는 것만 말한다.

**다시 찍기.** 스크립트는 [tests/demo/](../tests/demo/) 에 있다. Playwright 는 `v2/_run/demo/` 에 설치했다 (Git 밖).

```bash
cd v2/_run/demo                      # 처음 한 번: npm install playwright@1.56.1 && npx playwright install chromium
cp ../../tests/demo/*.mjs ../../tests/demo/cleanup.sh .
node demo.mjs --dry                  # 녹화 없이 단계마다 스크린샷 (step-*.png)
node demo.mjs                        # video/*.webm
bash cleanup.sh 2026-11-27           # 시연에서 만든 예약 취소 (날짜는 영상에서 고른 날)
```

Playwright 1.48 의 Chromium 은 이 PC 에서 실행되지 않았다 ("side-by-side configuration" 오류). 1.56 으로 올려서 됐다.
