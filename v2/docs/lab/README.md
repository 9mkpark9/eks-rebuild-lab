# 실습 — 보듬 동물병원 예약 시스템을 직접 옮겨 보기

소스에서 시작해 컨테이너, kubeadm 클러스터, EKS 로 같은 앱을 옮긴다. 실습마다 **실습 목표 → 사전 준비 → 단계별 명령과 출력 예 → 결과 확인 → 자원 정리** 순서다.

`# 출력 예` 는 모두 2026-11-25 에 이 순서대로 직접 실행해 받은 출력이다. 계정 번호, 공인 IP, join 토큰, RDS 주소의 일부는 가렸다. 인스턴스 ID, Pod 이름, 사설 IP 는 환경마다 다르다.

| 실습 | 내용 | 환경 | 걸리는 시간 (대략) |
|---|---|---|---|
| [lab01: 워크로드 직접 실행](lab01-워크로드-직접-실행.md) | jar 빌드, DB 초기화, 환경 변수로 서비스 실행, 세션과 Redis | WSL 2 | 20분 |
| [lab02: 이미지와 compose](lab02-이미지와-compose.md) | 두 단계 빌드, 6개 healthy, root 아님, 힙 상한, 정상·강제 종료 | WSL 2 | 20분 |
| [lab03: AWS 준비와 ECR](lab03-AWS-준비와-ECR.md) | CloudFormation 스택, ECR push | AWS | 10분 |
| [lab04: kubeadm 클러스터 구축](lab04-kubeadm-클러스터-구축.md) | init, join, Flannel, CoreDNS 분산, 볼륨 등록 | EC2 3대 | 25분 |
| [lab05: 앱 배포](lab05-앱-배포.md) | Secret, ECR 로그인, Kustomize, Probe, NodePort | kubeadm | 20분 |
| [lab06: 배포 운영](lab06-배포-운영.md) | 자동 복구, 롤링 업데이트, 롤백, DB 교체 뒤 데이터 | kubeadm | 20분 |
| [lab07: EKS](lab07-EKS.md) | gp2 문제, Auto Mode 노드, EBS, ALB | EKS | 25분 |
| [lab08: 선택 과제 RDS](lab08-선택-RDS.md) | 사설 서브넷, 초기화 Job, 두 클러스터가 함께 쓰는 RDS, 정리 | kubeadm + EKS | 30분 |

## 순서와 의존

```
lab01 ─▶ lab02 ─▶ lab03 ─▶ lab04 ─▶ lab05 ─▶ lab06
                     │                 │
                     └──────▶ lab07 ◀──┘ (같은 매니페스트)
                                │
                     lab05 + lab07 ─▶ lab08
```

## 비용

lab03 까지는 거의 무료다. lab04 부터 EC2, EKS, ALB, RDS 요금이 시간 단위로 나간다. 모두 켜 두면 시간당 약 0.55달러다. 쉬는 동안에는 각 실습의 **자원 정리** 에 있는 멈추기를, 끝나면 lab08 의 **모두 지우기** 를 한다.
